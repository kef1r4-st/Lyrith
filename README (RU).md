# ASCII Lyrics

ASCII Lyrics — виджет синхронизированного текста песен для **Serpantinum v2**. Он получает текущий трек и текст из встроенного источника `Lyrics` оболочки и отображает их локальным пиксельным шрифтом.

## Возможности

- Синхронизация текста песни и смены треков через встроенный источник `Lyrics`.
- Локальный пиксельный шрифт с поддержкой кириллицы.
- Перенос длинных строк и отдельное отображение текста в скобках.
- Анимированная смена названия трека.
- Плавное появление, раскрытие и смена строк песни.
- Когда музыка не воспроизводится, виджет показывает ссылку на GitHub.
- Отдельное меню настроек, открывающееся тройным нажатием левой кнопкой по виджету.

## Настройки

Открой меню тройным нажатием левой кнопкой по виджету.

**Цвета**
- **Основной цвет** — цвет главной строки текста песни.
- **Вторичный цвет** — цвет дополнительной строки, которая извлекается из текста в круглых скобках.
- Для обоих цветов доступны готовые палитры: нейтральные оттенки, красный, оранжевый, жёлтый, зелёный, бирюзовый, голубой, синий и фиолетовый.

**Размер текста**
- Малый.
- Средний.
- Крупный.

**Отображение**
- **Название трека** — показывает или скрывает строку с исполнителем и названием песни.
- **Вторая строка** — показывает или скрывает фрагменты текста, которые находятся в круглых скобках.
- **Анимация** — включает или отключает анимацию смены строк и названия трека.

**Внешний вид меню**
- **Прозрачность** — регулирует прозрачность фона меню. Значение можно менять ползунком от 20% до 100%.
- **Матовое стекло** — включает размытие фона и стеклянную тонировку. Когда режим включён, настройка прозрачности скрывается с плавной анимацией; при выключении ползунок появляется снова.

Изменения применяются сразу и сохраняются в конфигурации конкретного виджета средствами Serpantinum.

## Управление

1. Добавь **ASCII Lyrics** через редактор виджетов Serpantinum.
2. Трижды быстро нажми левой кнопкой по виджету, чтобы открыть настройки.
3. Выбирай цвета, размер текста и нужные переключатели. Изменения применяются сразу.
4. Если матовое стекло выключено, настрой прозрачность фона меню ползунком.
5. Закрой меню кнопкой **Готово**, нажатием вне меню или клавишей `Esc`.

Если меню не помещается по высоте, его содержимое можно прокручивать. Размеры меню ограничиваются доступной областью экрана.

## Требования и совместимость

- Serpantinum **v2**.
- Wayland-сеанс и поддерживаемый Serpantinum композитор: Hyprland, Niri, Sway или Mango.
- Доступный источник `Lyrics` внутри Serpantinum.
- Python 3 для запуска установщика и удаления.

Виджет использует внутренний реестр Serpantinum и его singleton `Lyrics`; отдельно от оболочки он не работает. Установка Serpantinum описана для Arch Linux и производных, Fedora и производных, Void Linux и NixOS. На других дистрибутивах может потребоваться адаптация.

## Установка

Сначала установи и запусти Serpantinum v2. Затем открой терминал в каталоге проекта и выполни:

```bash
python3 install.py
```

Установщик зарегистрирует виджет, скопирует QML-файл и шрифт, сохранит резервные копии изменяемых системных файлов и попросит Serpantinum перезагрузить конфигурацию. После этого добавь **ASCII Lyrics** через редактор виджетов.

Подробная инструкция находится в [docs/INSTALL.md](docs/INSTALL.md).

Официальная документация Serpantinum: https://serpantinum.dev/installation/

## Удаление

В каталоге проекта выполни:

```bash
python3 uninstall.py
```

Скрипт удалит регистрацию и установленные файлы ASCII Lyrics и восстановит резервные копии файлов оболочки, созданные установщиком. Сам Serpantinum не удаляется.

## Диагностика

Если виджет не появляется или меню не открывается:

1. Убедись, что Serpantinum v2 запущен и виджет добавлен через его редактор.
2. Проверь, что тип виджета зарегистрирован как `asciiLyrics`.
3. Повтори установку командой `python3 install.py` из каталога проекта.
4. Перезагрузи оболочку или перезапусти Wayland-сеанс.
5. Посмотри журнал Quickshell/Serpantinum:

```bash
journalctl --user -n 150 --no-pager
```

Виджет не ищет тексты самостоятельно. Отображение зависит от того, получает ли встроенный источник `Lyrics` текст текущего трека.
