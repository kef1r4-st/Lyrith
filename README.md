# Lyrith
# Lyrith  — небольшой виджет для отображения текста текущей песни прямо на рабочем столе. Он синхронизируется с воспроизведением музыки и показывает строки по мере их появления, чтобы не приходилось каждый раз открывать плеер или искать текст отдельно.
